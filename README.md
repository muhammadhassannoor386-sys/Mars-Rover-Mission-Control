
# Mars Rover Mission Control

## Project Description

Mars Rover Mission Control is a software system designed
to control and monitor a rover operating on the surface of Mars.

## Main Features

- Move the rover
- Rotate the rover
- Display rover position
- Display rover direction
- Process movement commands
- Detect obstacles
- Handle invalid commands
